\# EcoFuturo ESUDA - Back-end



API Back-end em Python/FastAPI para o projeto de mobilidade sustentável da Faculdade ESUDA.



\## 🛠️ Tecnologias

\- Python 3.12

\- FastAPI

\- Uvicorn

\- Supabase (PostgreSQL)

\- JWT e Bcrypt



\## 📋 Funcionalidades

\- Cadastro e Login (com token JWT)

\- Registro de atividades sustentáveis e cálculo de CO2

\- Catálogo de benefícios e resgates (vouchers)

\- Relatórios, ranking, missões e medalhas

\- Painel do Administrador



\## 🚀 Como rodar localmente

1\. Crie o ambiente virtual: `python -m venv venv`

2\. Ative o ambiente: `venv\\Scripts\\activate`

3\. Instale as dependências: `pip install -r requirements.txt`

4\. Rode o servidor: `uvicorn main:app --reload`

5\. Acesse o Swagger em: `http://127.0.0.1:8000/docs`
